# 霓虹贪吃蛇 (Neon Snake)

一个零依赖、单文件实现的 HTML5 Canvas 霓虹风格贪吃蛇小游戏，支持桌面键盘与移动端触屏操作。

## 特性
- 单文件零依赖（直接双击 `index.html` 即可运行，也支持 GitHub Pages 一键部署）
- 霓虹发光视觉风格、粒子消除特效与限时金色星星奖励
- 三档初始速度（悠闲 / 标准 / 极速）及随得分提升的动态加速
- 内置 Web Audio API 合成音效，支持一键静音
- 本地自动保存历史最高分

## 操作方式
- **键盘**：方向键 / `WASD` 控制方向，`Space` 暂停/继续，`R` 重新开始
- **触屏**：在棋盘上滑动或点击底部方向键
